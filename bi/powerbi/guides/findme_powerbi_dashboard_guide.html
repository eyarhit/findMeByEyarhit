Comment créer la navigation dans Power BI

Barre de navigation avec boutons sur chaque page

Méthode recommandée : boutons de navigation natifs
1Créer 4 pages dans votre rapport PBIP : nommez-les exactement 01 - Executive, 02 - Managerial, 03 - Operationnel, 04 - Technique
2Sur chaque page, insérer un rectangle en haut (hauteur ≈ 50px, fond sombre). C'est votre barre de nav.
3Insérer → Bouton → choisir Navigation dans la page. Répéter pour chaque page cible.
4Dans le panneau Format bouton → Action → Type = Navigation dans la page → Destination = page souhaitée.
5Styliser les 4 boutons : fond neutre pour les inactifs, fond coloré pour la page courante. Copier-coller la barre sur toutes les pages.
6Pour indiquer la page active : créer un signet par page avec le bouton correspondant en état sélectionné. Assigner le signet à l'action du bouton.

Astuce : signets pour état actif

Dans Affichage → Signets, créez un signet par page. Nommez-les Nav_Executive, Nav_Managerial, etc. Assignez chaque signet au bouton correspondant dans l'onglet Action. Ainsi, le bouton de la page courante peut avoir un état visuel différent (surligné, gras, souligné).
