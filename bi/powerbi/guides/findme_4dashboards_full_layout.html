Guide complet des 4 dashboards Power BI Find-Me avec visuels, mesures DAX et filtres

01 — Executive dashboard Vue stratégique · recrutement mensuel
Cartes KPI (ligne du haut)
Total candidatures
—
SUM(candidatures)
Candidatures acceptées
—
SUM(acceptees)
Taux acceptation
— %
DIVIDE(accept,total)*100
Total missions
—
SUM(mission_count)
Missions ouvertes
—
status = "OPEN"
Visuels principaux
Graphique en courbes
Évolution mensuelle des candidatures
Axe X : month_num · Axe Y : KPI Candidatures
Source : v_bi_kpi_recrutement
Histogramme groupé
Acceptées vs refusées par mois
Axe X : month_num · Valeurs : acceptees / refusees
Source : v_bi_kpi_recrutement
Graphique aire
Taux acceptation % sur le temps
Axe X : month_num · Axe Y : KPI Taux %
Source : v_bi_kpi_recrutement
Barres horizontales
Top missions par nb de candidatures
Axe Y : mission_name · Axe X : candidatures
Source : v_bi_candidature
Filtres / segments
Segment année obligatoire
v_bi_kpi_recrutement[year_num]
Plage de dates
dim_date[full_date]
Type contrat
v_bi_mission[type_contrat]
Ne pas utiliser dim_date[year_num] comme segment — colonne non unique. Utiliser uniquement v_bi_kpi_recrutement[year_num].
Mesures DAX à créer (table : v_bi_kpi_recrutement)
KPI Candidatures
KPI Candidatures = SUM(v_bi_kpi_recrutement[candidatures])
KPI Acceptées
KPI Acceptées = SUM(v_bi_kpi_recrutement[acceptees])
KPI Refusées
KPI Refusées = SUM(v_bi_kpi_recrutement[refusees])
Taux acceptation %
KPI Taux % = DIVIDE([KPI Acceptées],[KPI Candidatures],0)*100
Missions ouvertes (table : v_bi_mission)
Missions ouvertes = CALCULATE(SUM(v_bi_mission[mission_count]),v_bi_mission[status_mission]="OPEN")
02 — Managerial dashboard Candidatures & missions enrichies
Cartes KPI (ligne du haut)
Candidatures (vue)
—
SUM(candidature_count)
Acceptées
—
SUM(is_accepted)
Refusées
—
SUM(is_refused)
En cours
—
SUM(is_en_cours)
Missions publiées
—
SUM(mission_count)
Visuels principaux
Graphique en anneau
Répartition par statut candidature
Légende : statut_candidature
Valeur : Candidatures (vue)
Source : v_bi_candidature
Barres groupées
Missions par type de contrat
Axe X : type_contrat (CDI,CDD…)
Valeur : Missions (vue)
Source : v_bi_mission
Courbes multiséries
Candidatures & missions par mois
Axe X : month_name · 2 séries
Source : v_bi_candidature + v_bi_mission
Carte géographique
Missions par ville / pays
Emplacement : ville ou pays
Taille bulles : mission_count
Source : v_bi_mission
Tableau détail
Détail par mission
Colonnes : mission_name, reference_code,
type_contrat, statut, ville, candidatures
Source : v_bi_candidature
Barres empilées
Acceptées + refusées par ville
Axe X : ville · Empilé : is_accepted / is_refused
Source : v_bi_candidature
Filtres / segments
Segment année
v_bi_candidature[year_num]
Ville / Pays
v_bi_mission[ville]
Type contrat
v_bi_mission[type_contrat]
Statut candidature
v_bi_candidature[statut_candidature]
Télétravail
v_bi_mission[is_remote]
Mesures DAX à créer
Candidatures (vue) v_bi_candidature
Candidatures (vue) = SUM(v_bi_candidature[candidature_count])
Acceptées / Refusées / En cours
Acceptées (vue) = SUM(v_bi_candidature[is_accepted]) Refusées (vue) = SUM(v_bi_candidature[is_refused]) En cours (vue) = SUM(v_bi_candidature[is_en_cours])
Taux acceptation (vue) %
Taux % (vue) = DIVIDE([Acceptées (vue)],[Candidatures (vue)],0)*100
Missions (vue) v_bi_mission
Missions (vue) = SUM(v_bi_mission[mission_count]) Missions remote = CALCULATE([Missions (vue)],v_bi_mission[is_remote]=1)
03 — Dashboard opérationnel Utilisateurs · notifications · CV · compétences
Cartes KPI (ligne du haut)
Total utilisateurs
—
SUM(user_count)
Total notifications
—
SUM(notification_count)
Notif. lues
—
is_read = 1
Taux lecture
— %
lues / total * 100
Total CV
—
SUM(cv_count)
Étapes moy. CV
—
AVERAGE(steps_completed)
Total favoris
—
SUM(favori_count)
Visuels principaux
Top 10 compétences
Compétences les plus utilisées dans les CV
Axe Y : skill_label · Axe X : usage_count
Tri décroissant · Source : dim_skill
Répartition par rôle
Candidats vs recruteurs vs autres
Légende : role_name
Valeur : Total utilisateurs
Source : dim_user
Activité par jour/semaine
Inscriptions et CV dans le temps
Axe X : dim_date[full_date]
Séries : CV + notifications
CV par étapes complétées
Distribution du nb d'étapes
Axe X : steps_completed · Axe Y : count
Source : fact_cv
Catégories compétences
Langages vs Frameworks vs Outils
Légende : skill_category
Valeur : Total usages compétences
Source : dim_skill
Notifications par jour
Volume envoyé vs lu dans le temps
Axe X : dim_date[full_date]
Séries : total notif. + lues
Source : fact_notification
Filtres / segments
Plage de dates
dim_date[full_date]
Rôle utilisateur
dim_user[role_name]
Pays utilisateur
dim_user[country]
Catégorie skill
dim_skill[skill_category]
Mesures DAX à créer
Utilisateurs fact_user
Total utilisateurs = SUM(fact_user[user_count])
Notifications fact_notification
Total notifications = SUM(fact_notification[notification_count]) Notifications lues = CALCULATE([Total notifications],fact_notification[is_read]=1) Taux lecture % = DIVIDE([Notifications lues],[Total notifications],0)*100
CV fact_cv
Total CV = SUM(fact_cv[cv_count]) Étapes moyennes = AVERAGE(fact_cv[steps_completed])
Compétences dim_skill
Total usages = SUM(dim_skill[usage_count]) Top compétence = CALCULATE(SELECTEDVALUE(dim_skill[skill_label]),TOPN(1,ALL(dim_skill),[Total usages]))
Favoris fact_mission_favori
Total favoris = SUM(fact_mission_favori[favori_count])

Cartes KPI (ligne du haut)

—
SUM(attempt_count)

AVERAGE(score)
Taux réussite quiz
— %

—
SUM(session_count)
Score moyen CDG

AVERAGE(score)
Dernier refresh ETL
—
MAX(finished_at) OK
Visuels principaux
Scores par framework
Performance CodinGame par techno
Axe Y : framework_name
Axe X : Score moyen CDG %
Source : fact_codingame
Évolution scores quiz
Score moyen dans le temps
Axe X : dim_date[full_date]
Axe Y : Score moyen quiz
Source : fact_quiz
Taux réussite quiz
Réussis vs échoués
Valeur : passed = 1 vs 0
Source : fact_quiz
Tentatives par utilisateur

Axe X : user_key · Axe Y : attempt_count
Source : fact_quiz

status, rows_loaded, error_message

Sessions CDG par mois
Volume évaluations techniques
Axe X : dim_date[month_name]
Axe Y : Sessions codingame
Source : fact_codingame
Filtres / segments
Plage de dates
dim_date[full_date]
Framework CDG
fact_codingame[framework_name]
Quiz réussi
fact_quiz[passed]
Statut ETL
etl_run_log[status]
Mesures DAX à créer
Quiz fact_quiz
Tentatives quiz = SUM(fact_quiz[attempt_count]) Score moyen quiz = AVERAGE(fact_quiz[score]) Taux réussite quiz % = DIVIDE(CALCULATE([Tentatives quiz],fact_quiz[passed]=1),[Tentatives quiz],0)*100
CodinGame fact_codingame
Sessions codingame = SUM(fact_codingame[session_count]) Score moyen CDG = AVERAGE(fact_codingame[score]) Score CDG % = DIVIDE(AVERAGE(fact_codingame[score]),AVERAGE(fact_codingame[total_score]),0)*100
ETL fraîcheur etl_run_log
Dernier refresh OK = CALCULATE(MAX(etl_run_log[finished_at]),etl_run_log[status]="OK")
