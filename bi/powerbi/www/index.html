Power BI — Find-Me (PFE BI ESB)

Stack conforme au cours : Talend (ETL) + Power BI (dashboards) + entrepôt findme_dw (étoile).

1. Lancer l’ETL Talend (Docker)

docker compose run --rm talend-etl

Attendu : ETL terminé avec succès.

2. Connexion Power BI Desktop → MySQL

  • Serveur : localhost:3306 (Docker MySQL)
  • Base : findme_dw
  • Utilisateur : findme_bi / findme_bi_readonly

Importer les tables : dim_date, dim_localisation, dim_mission, fact_candidature, etc.

3. Rapports (.pbix)

Créer ou ouvrir les modèles décrits dans bi/powerbi/reports/README.md : Executive, Managérial, Opérationnel.

Dimensions cours : Temps (dim_date), Localisation (dim_localisation).

4. Talend Open Studio

Job documenté : bi/talend/studio/GUIDE_TALEND_OPEN_STUDIO.md
